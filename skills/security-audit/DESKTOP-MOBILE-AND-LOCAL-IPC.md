# 桌面、移动端与本地 IPC 狩猎

#### 何时使用本文件

当目标是桌面或移动应用、特权辅助进程、更新器、本地守护进程、webview 宿主、深度链接处理器、浏览器原生消息宿主或本地 IPC 客户端/服务器时，使用本文件。相关的不受信任行为者可能是下载的文档、远程 Web 内容、另一个本地应用、另一个操作系统用户、沙箱进程或低权限账户。明确说明起始能力，而不是把所有本地用户视为等价。

浏览器侧 webview 行为使用 `CLIENT-SIDE.md`，原生内存与加载器安全使用 `MEMORY-SAFETY-AND-BINARY.md`，更新真实性使用 `SUPPLY-CHAIN-AND-RELEASE.md`。

## 核心纪律（本领域每个 agent 提示词均须包含）

```
- 确定现实的本地或远程内容攻击者：另一个应用、另一个操作系统用户、沙箱子进程、不受信任的文档或远程源。同一账户和权限内的自害不构成边界违规。
- 路径、进程名、bundle/包 ID 和声明的发送方字段不是对等身份认证。使用操作系统对等凭据、代码身份、能力句柄或受保护的通道状态。
- 原生桥或辅助进程必须在解析后对每个操作和最终资源进行授权。受信任的 UI 或代理不会使攻击者可影响的参数变得可信。
- 操作系统沙箱、签名、entitlement、权限、钥匙串 ACL、导出组件策略和提示行为在固定且可见时是真实控制。
- 源码证据加有界本地/模拟器测试使用 `confirmed`。需要签名、清单合并、操作系统版本、设备策略、安装器 ACL 或打包但不可观测时使用 `needs_validation`。
```

## 深度链接、回调与导航攻击类别（subagent_type: `general`）

**自定义 scheme 与深度链接歧义**
另一个应用或页面可以调用某个路由，该路由在没有当前会话和一次性回调绑定的情况下变更状态、导入数据、完成认证或选择账户。审查 URI 规范化、重复查询字段、scheme/host/path 匹配、导出 activity/handler 策略以及过期/重放的链接。

**应用与账户交接混淆**
OAuth、SSO、magic-link、邀请、设备配对、无密码或支付回调返回到错误的已安装应用、配置文件、租户或待处理事务。将状态绑定到发起应用身份、当前会话、账户、提供方、操作和过期时间。

**文件打开与 intent 权限混淆**
关联文件、分享 intent、拖放项、剪贴板/粘贴板记录、通知操作或打开文件事件在未确认内容类型、发送方信任（如适用）、当前用户意图和最终目标的情况下触发特权操作。

## Webview 与原生桥攻击类别（subagent_type: `general`）

**导航源到桥的混淆**
远程或攻击者控制的 frame 可以访问仅为打包内容设计的 JavaScript/原生桥。在调用时以及每次导航、重定向、子 frame 创建、弹窗和错误/回退页面之后验证源。URL 前缀检查和初始加载检查不足。

**过宽的原生桥能力**
Web 内容可以通过通用桥选择任意文件、命令、IPC 方法、凭据或系统操作。检查方法允许列表、规范化参数、用户/租户权限、手势/确认要求以及返回值泄露。

**Webview 文件与通用访问**
远程内容可以读取应用本地文件、特权自定义 scheme 或内部源，因为文件访问、通用访问、混合内容、调试接口或自定义协议处理器意外地连接了源。缺少限制性设置但没有可达的受保护内容属于加固项。

## 本地 IPC 与导出组件攻击类别（subagent_type: `general`）

**IPC 对等身份认证缺口**
Unix socket、命名管道、XPC、Binder、D-Bus、原生消息、RPC、共享内存或回环监听器接受低信任对等方，而未检查操作系统凭据、代码身份、沙箱令牌或通道所有权。要求通道背后有有意义的方法或信息披露。

**声明主体与通道身份**
已认证的进程/通道属于一个应用或用户，但请求字段选择了另一个用户、租户、配置文件或能力。将每个方法和资源绑定到对等凭据，而非调用方声明的标识符。

**导出服务、activity、receiver 或 provider 越权**
移动组件或本地自动化端点可被外部调用，并执行本应仅供应用自身使用的操作。审查最终合并的清单、intent filter、权限/签名级别、路径授权和备用别名。打包后清单状态未知需要 `needs_validation`。

**IPC 生命周期与关联混淆**
可预测的请求 ID、复用的句柄、过期的通道、继承的描述符、全局可写的 socket 路径或重启行为，使一个对等方可以应答、取消或复用另一个对等方的操作。审查 socket 文件、锁、端口和共享映射的创建权限与清理。

## 特权辅助进程与本地文件攻击类别（subagent_type: `general`）

**特权辅助进程作为混淆代理**
低权限调用方可以在没有逐操作授权的情况下选择特权命令、文件、服务、用户或系统设置。审查 sudo/polkit/UAC/XPC 辅助进程规则，确保辅助进程独立验证规范化参数。

**安装、更新与修复路径信任**
特权安装器/辅助进程在授权后读取低信任行为者可写的清单、脚本、包、符号链接、工作目录或修复状态。将授权绑定到不可变内容和安全的目标路径。

**本地文件所有权与 TOCTOU**
应用检查文件/路径后，在特权读/写期间跟随替换、符号链接、挂载或大小写/规范化变更。使用相对描述符的操作并验证最终所有权。`MEMORY-SAFETY-AND-BINARY.md` 聚焦于文件打开后的解析。

**凭据存储与本地机密边界不匹配**
钥匙串/keystore 项、令牌文件、备份、日志、剪贴板、通知预览或本地配置可被权限更低的另一个应用/配置文件/用户读取。仅同一预期操作系统账户可读的明文不自动构成漏洞；说明低信任读取者及其凭据能力。

## 应用状态与设备生命周期攻击类别（subagent_type: `general`）

**账户切换、登出与设备恢复泄露**
缓存数据、后台任务、小组件、通知、本地数据库、webview 存储或生物识别批准在登出/账户切换后仍然存在，并出现在后续账户下。审查备份/恢复和多配置文件行为。

**待处理操作与用户在场混淆**
通知、小组件、快捷方式、分享面板、生物识别提示或延迟操作授权的操作与显示的不同、在过期后执行，或使用另一个配置文件的待处理状态。将确认绑定到规范化操作、资源、账户和当前前台状态。

## 通用动作（适用于以上所有类别）

- 枚举每个进程、应用组件、本地端点、URI scheme、文件关联、webview 源和辅助进程。记录操作系统身份、运行时权限、调用方和可调用操作。
- 读取最终打包输入：合并清单、entitlement、安装器规则、原生消息注册、协议处理器和 ACL 创建。源码声明可能在下游被覆盖。
- 在隔离机器/模拟器上使用虚拟配置文件和敏感度低的本地夹具进行验证。不要与其他用户的应用、凭据或生产服务交互。

## 验证规则（在此报告任何发现之前适用）

1. 说明攻击者起始能力、跨越的操作系统/应用主体、入口通道、接受的参数或状态，以及未授权操作或泄露。
2. 确认适用的操作系统沙箱、对等凭据、签名、entitlement、权限、用户同意和安装器控制。未知的打包/运行时事实需要 `needs_validation`。
3. 对于 webview 桥，同时引用导航/源控制和特权原生 sink。对于 IPC，引用对等身份认证和逐资源授权。对于辅助进程，验证最终规范化目标。
4. 保持本地测试有界，使用虚拟内容/账户。证明边界结果后停止；不要将证明扩展到持久化或更广泛的系统修改。
5. 仅在拥有完整源码和本地证据链时返回 `confirmed`。返回 `needs_validation` 时附上所需的确切操作系统、清单、签名、ACL 或设备生命周期事实。
